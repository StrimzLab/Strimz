> **Read-only mirror of the Strimz smart contracts.** This repository is copied automatically from Strimz's own repository after every change, so it always matches what's deployed next. Pull requests here aren't merged; email support@strimz.finance instead.
>
> Dependencies are git submodules in Strimz's repository and aren't copied here. Install them at the versions pinned in [`foundry.lock`](foundry.lock):
>
> ```sh
> forge install foundry-rs/forge-std@v1.16.0 OpenZeppelin/openzeppelin-contracts@v5.6.1 \
>   OpenZeppelin/openzeppelin-contracts-upgradeable@v5.6.1 OpenZeppelin/openzeppelin-foundry-upgrades@v0.4.0
> ```
>
> The SDKs are at [strimz-sdk](https://github.com/StrimzLab/strimz-sdk), and the docs at [docs.strimz.finance](https://docs.strimz.finance/docs). MIT licensed.
