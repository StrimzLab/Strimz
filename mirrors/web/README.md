# Strimz website and docs

The source of [strimz.finance](https://strimz.finance) (`apps/web`) and [docs.strimz.finance](https://docs.strimz.finance) (`apps/docs`). Both are Next.js apps that run on Cloudflare Workers.

> **Read-only mirror.** This repository is copied automatically from Strimz's own repository after every change. The apps build only inside Strimz's workspace, which holds the shared UI and config they import, so this copy is for reading. Pull requests here aren't merged; email support@strimz.finance instead.

- The docs content is in [`apps/docs/content/docs`](apps/docs/content/docs).
- The SDKs are at [strimz-sdk](https://github.com/StrimzLab/strimz-sdk), and the smart contracts at [strimz-contracts](https://github.com/StrimzLab/strimz-contracts).
