# Live mode only

ADR: [ADR-2026-11-22-live-only](../adr/ADR-2026-11-22-live-only.md). It supersedes the sandbox plan in ADR-2026-10-12-one-chain-one-mode.

## For merchants

- **One live environment on Arc mainnet,** with `sk_live_` and `pk_live_` keys. There is no test mode and no test keys.
- **New docs page, "Testing your integration".** It replaces "Test mode vs live mode" and explains how to try Strimz with a small real payment, such as 1 USDC. The payment comes back to the merchant's own wallet, and on the Free plan the fee is refunded.
- **The docs examples use live keys** throughout. The faucet and testnet steps are gone from merchant pages.
- **Dashboard:**
  - the Test/Live badge is gone from the top bar;
  - the Mode field and column are gone from API keys;
  - the getting-started checklist no longer mentions test mode, or a "test event" button that never existed.

## For operators

- **`docs/runbooks/live-and-sandbox-deployments.md`** is now `docs/runbooks/live-deployment.md`, covering the single mainnet deployment.
- **The testnet deployment** stays Strimz's internal development environment until mainnet.
- **No code paths changed.** `mode` columns and the `mode_unavailable` refusal remain.

## Tests

- The existing dashboard and docs suites pass.
