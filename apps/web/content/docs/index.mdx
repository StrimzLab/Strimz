# Welcome to Strimz

Strimz is a **billing infrastructure** for accepting, managing, and settling stablecoin payments on the Arc blockchain. One API for one-shot payments, recurring subscriptions, refunds, agent escrow, and cross-chain settlement.

These docs are built with [Fumadocs](https://fumadocs.vercel.app/) and live in the same Next.js app as the marketing site and dashboard. The MDX source is in [`apps/web/content/docs`](https://github.com/StrimzLab/strimz/tree/main/apps/web/content/docs) — pull requests welcome.
