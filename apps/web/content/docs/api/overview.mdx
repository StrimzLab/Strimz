The Strimz API is a single host (`https://api.strimz.finance`) serving JSON over HTTPS. Every endpoint is documented in [OpenAPI](https://api.strimz.finance/openapi.json) and rendered by [Scalar](https://api.strimz.finance/docs) for an interactive "try it" experience.

## Base URL

```
https://api.strimz.finance
```

Each Strimz deployment runs in one mode. The sandbox runs on Arc
testnet and accepts `sk_test_` keys only; the live deployment runs on
Arc mainnet and accepts `sk_live_` keys only. A key of the other mode
returns `403 mode_unavailable`. See [Authentication](/docs/authentication).

## Authentication

```http
Authorization: Bearer sk_live_xxx
```

See [Authentication](/docs/authentication) for the full breakdown.

## Errors

Every error returns a JSON envelope:

```json
{
  "error": {
    "code": "invalid_request",
    "message": "amount must be a positive integer string",
    "param": "amount",
    "details": { "issues": [...] },
    "requestId": "req-4f2"
  }
}
```

The full code list is on [Errors](/docs/errors). Always include the
`requestId` when reporting an issue; it's the key support uses to
find your request in the logs.

## Pagination

List endpoints return:

```json
{
  "data": [...],
  "nextCursor": "cmh3lmkw50000xv8d12345678",
  "hasMore": true
}
```

Pass `?cursor=<nextCursor>` on the next call. `limit` defaults to 25, max 100.

## Idempotency

Send an `X-Strimz-Idempotency-Key` header on a `POST` or `PATCH` and the API replays the first response for that key for 24 hours. The SDK sends one on every write. See [Idempotency](/docs/concepts/idempotency).

## Rate limits

The API allows 600 requests per minute per IP across all routes. Some routes have a tighter limit of their own. Exceeding a limit returns `429`.

## Resources

Every resource has its own page in the sidebar. The most-used ones:

- **[Refunds](/docs/api/refunds).** Server-intent plus wallet-signed transfers.

A one-line sanity check against the test API:

```bash
curl https://api.strimz.finance/v1/merchants/me \
  -H "Authorization: Bearer sk_test_xxxxxxxxxxx"
```
