`/conversion`, `/churn` and `/volume` take optional `?from=ISO8601&to=ISO8601` query params.

## Conversion

```http
GET /v1/stats/conversion?from=2026-04-01&to=2026-04-30
```

Daily buckets:

```json
{
  "from": "...",
  "to":   "...",
  "data": [
    { "day": "2026-04-01", "created": 124, "confirmed": 89, "rate": 0.7177 },
    ...
  ]
}
```

`rate = confirmed / created` per UTC day.

## Churn

```http
GET /v1/stats/churn
```

Monthly churn rate over the last 12 months. Numerator: subs that flipped to `cancelled` or `lapsed` in that month. Denominator: total subs created in that month.

## Amounts per currency

Every money figure is a `CurrencyAmounts` object with one base-unit string per payment
currency. Both currencies are always present; a currency with no activity is `"0"`.
USDC and EURC are never added together, and Strimz does not convert between them.

```json
{ "USDC": "60000000", "EURC": "9000000" }
```

The schemas and types for every response below ship in `@strimz/shared-types`
(`statsSummarySchema`, `statsVolumeSchema`, `statsMrrSchema`, `statsLtvSchema`,
`statsForecastSchema`).

GET /v1/stats/summary

## Volume

```http
GET /v1/stats/volume?from=2026-09-03T00:00:00Z&to=2026-10-03T00:00:00Z
```

Daily confirmed inbound volume, one row per UTC day and currency that had volume, ordered
by day then USDC before EURC. `from` and `to` are ISO timestamps; they default to the
last 30 days and may be at most 366 days apart. Empty days are omitted.

```json
{
  "from": "2026-09-03T00:00:00.000Z",
  "to": "2026-10-03T00:00:00.000Z",
  "data": [
    {
      "day": "2026-10-01",
      "currency": "USDC",
      "count": 2,
      "gross": "15000000",
      "fees": "150000",
      "net": "14850000"
    },
    {
      "day": "2026-10-01",
      "currency": "EURC",
      "count": 1,
      "gross": "3000000",
      "fees": "30000",
      "net": "2970000"
    }
  ]
}
```

## MRR

```http
GET /v1/stats/mrr
```

```json
{
  "mrr": { "USDC": "60000000", "EURC": "9000000" },
  "activeSubscribers": 4
}
```

Only `active` subscriptions count. Each subscription is interval-normalised on its own:
`daily × 30`, `weekly × 30/7`, `monthly`, `quarterly / 3`, `yearly / 12`, then summed
within its currency. Returns gross MRR; for net subtract your tier's per-transaction fee.

## LTV

```http
GET /v1/stats/ltv?currency=USDC&limit=25
```

Top customers by lifetime spend in one currency. `currency` is required (`USDC` or
`EURC`); without it the API answers `400 invalid_request`. Spend is the gross amount of
confirmed inbound transactions. A payment is attributed to the customer on the
transaction, or else to the customer of its payment session or subscription.

```json
{
  "currency": "USDC",
  "data": [{ "customerId": "cus_xyz", "totalSpend": "500000000", "transactionCount": 12 }],
  "nextCursor": "eyJzIjoiNTAwMDAwMDAwIiwiYyI6ImN1c194eXoifQ",
  "hasMore": true
}
```

Pass `nextCursor` back as `cursor` for the next page. `limit` is 1 to 100, default 25.

## Forecast

```http
GET /v1/stats/forecast
```

One linear regression per currency over that currency's daily net revenue for the last
90 days. Days with no revenue count as zero, from the first day with revenue up to
yesterday. `nextN` is the sum of the projected daily values over the next N days, never
below zero.

```json
{
  "byCurrency": {
    "USDC": {
      "confidence": "medium",
      "last90DayRevenue": "900000000",
      "next30": "320000000",
      "next60": "650000000",
      "next90": "990000000"
    },
    "EURC": {
      "confidence": "low",
      "last90DayRevenue": "10000000",
      "next30": "0",
      "next60": "0",
      "next90": "0"
    }
  }
}
```

Confidence per currency: `low` below 30 days with revenue, `medium` from 30, `high` from 60. Fewer than 7 days with revenue gives `low` and zero projections.
`last90DayRevenue` is always the real 90-day total.
