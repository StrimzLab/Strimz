This page takes you from zero to a confirmed payment in your
dashboard. Every command here works as written. No placeholders.

<Callout title="Prerequisites" type="info">
  - Node.js 18+ or Bun 1.0+ (or any HTTP client) - A wallet with a little USDC on Arc, for example 1
  USDC. See [Testing your integration](/docs/testing).
</Callout>

<Steps>

<Step>

### Create your account

Go to [app.strimz.finance/signup](https://app.strimz.finance/signup). Sign up with Google or your email; after
that you can also sign in with a passkey. Strimz uses [Privy](https://privy.io) under
the hood, and Privy creates an embedded Arc wallet for you in the background.

You don't need to do anything with the embedded wallet right now. It's
useful later if you want to receive payouts without connecting an external
wallet.

</Step>

<Step>

### Issue an API key

In the dashboard, open **API keys** and click **Issue key**. You'll get a
string that starts with `sk_live_`. Copy it
straight away. The full key is only shown once. If you lose it, revoke it
and issue a new one.

```bash
export STRIMZ_KEY=sk_live_xxxxxxxxxxxxxxxxxxxx
```

<Callout title="Keep it on your server" type="info">
  A secret key can create payments and manage your account. Store it in your server's environment
  and never put it in browser code.
</Callout>

</Step>

<Step>

<Step>

### Create your first payment session

A **payment session** is a hosted checkout. You create one on the server
and send your customer to the `checkoutUrl` it returns. They connect a
wallet, sign the payment, and Strimz fires a webhook once it confirms
on-chain.

<Tabs items={['TypeScript', 'curl']}>
  <Tab value="TypeScript">
    ```ts title="server.ts"
    import { StrimzClient } from '@strimz/sdk'

    const strimz = new StrimzClient({ apiKey: process.env.STRIMZ_KEY! })

    const session = await strimz.paymentSessions.create({
      amount: '50000000',          // 50 USDC, expressed in 6-decimal units
      currency: 'USDC',
      description: 'Pro plan, August',
      successUrl: 'https://your-site.com/thanks',
      cancelUrl:  'https://your-site.com/cancelled',
    })

    console.log(session.checkoutUrl)
    ```

  </Tab>
  <Tab value="curl">
    ```bash
    curl https://api.strimz.finance/v1/payment-sessions \
      -H "Authorization: Bearer $STRIMZ_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "amount": "50000000",
        "currency": "USDC",
        "description": "Pro plan, August",
        "successUrl": "https://your-site.com/thanks",
        "cancelUrl":  "https://your-site.com/cancelled"
      }'
    ```
  </Tab>
</Tabs>

Open the printed `checkoutUrl` in a browser, connect a wallet
that holds a little USDC on Arc, and pay. A small amount such as 1 USDC is enough. Now refresh the
**Payment sessions** page in your dashboard. You'll see the new session,
and within a few seconds its status moves from `created` to `confirmed`.

<Callout title="It comes back to you" type="info">
  The payment lands in your own payout wallet, and on the Free plan the fee is refunded. See
  [Testing your integration](/docs/testing).
</Callout>

</Step>

<Step>

### Receive your first webhook

Polling for state changes works but it gets old fast. A webhook
endpoint is the right shape. Register it from your server with the same
`StrimzClient`. Your secret key never belongs in browser code:

```ts title="server.ts"
const endpoint = await strimz.webhookEndpoints.create({
  url: 'https://your-site.com/webhooks/strimz',
  events: ['payment.completed', 'payment.failed'],
  mode: 'live',
})

console.log(endpoint.signingSecret) // shown ONCE. Store it now.
```

Now wire the receiver. It runs on your server and must verify the raw
request body, exactly as received, before anything parses it. This
Express example uses `express.raw` so `req.body` is the unparsed bytes:

```ts title="receiver.ts"
import express from 'express'
import { verifyWebhookSignature } from '@strimz/sdk'

const app = express()

app.post('/webhooks/strimz', express.raw({ type: 'application/json' }), async (req, res) => {
  const payload = req.body.toString('utf8')
  const result = await verifyWebhookSignature(
    payload,
    req.get('strimz-signature') ?? '',
    process.env.STRIMZ_WEBHOOK_SECRET!,
  )
  if (!result.valid) return res.status(401).end()

  const event = JSON.parse(payload)
  switch (event.type) {
    case 'payment.completed':
      console.log('payment confirmed:', event.data.session.id, event.data.session.amount)
      break
    case 'payment.failed':
      console.error('payment failed:', event.data.session.id)
      break
  }
  res.status(200).end()
})
```

`verifyWebhookSignature(payload, signatureHeader, secret)` is async. It
resolves to `{ valid: true }` or `{ valid: false, reason }`, so always
`await` it and check `result.valid`: the unawaited Promise is always
truthy. It does a timing-safe equality check and rejects anything older
than 300 seconds. The signature format and the algorithm
itself are documented on [Verifying webhooks](/docs/guides/webhooks).

</Step>

</Steps>

## What you just did

You signed up, issued an API key, created a hosted checkout, took a
real payment, and wired a webhook to react to it. This is already your
production setup: point the webhook at your real URL and go.
